# Proyecto de Movilidad en Chile

Este proyecto tiene como objetivo analizar datos de movilidad global (Google COVID-19) enfocados en Chile, aplicando un flujo profesional de ciencia de datos.

## Objetivo
Transformar un dataset crudo en un análisis limpio, reproducible y documentado utilizando Python, Pandas y Scikit-Learn.

## Etapas del Proyecto

### 1. Limpieza de Datos
- Filtrado de datos para Chile
- Manejo de valores nulos
- Eliminación de duplicados
- Detección de outliers

### 2. Transformación de Datos
- Conversión de fechas a formato datetime
- Creación de variable `movilidad_promedio`
- Escalamiento de variables numéricas
- Codificación de subregiones

### 3. Visualización
- Gráfico de línea de la movilidad promedio en el tiempo

## Tecnologías
- Python
- Pandas
- Scikit-Learn
- Matplotlib / Seaborn
- Jupyter Notebook / Google Colab

## Estructura
